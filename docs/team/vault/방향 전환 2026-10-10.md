# 방향 전환 (사용자 결정 2026-10-10 12시대)

관련: [[PM 검토 기록]], [[작업 규칙]], [[흡수 현황]]

사용자가 지인(실사용자) 의견을 듣고 정한 방향이다. 아래가 앞선 결정과 부딪히면 **이 문서가 우선**이다.

## 1. 목표 사이트에 로아랩 추가, 중복 기능은 로아랩 기준

- 로아랩: https://lo4.app (음돌·치명타 계산·**딜러 전투력 시뮬레이터**(2026-02 오픈 베타)·적정 치적 계산기 lo4.app/tools/blunt-thorn 등).
- 목표 사이트(일로아·로아와·클로아·로펙·로아랩)는 계속 **전부 흡수**한다. **여러 사이트에 같은 기능이 있으면 로아랩 기준**(계산 방식·기능 범위·입력 항목)으로 맞춘다.
- 실사용자 의견: 요즘은 **로펙 점수보다 전투력이 중요**하다. 로아랩은 "현재 세팅에서 무엇을 어떻게 바꾸면 전투력이 얼마로 바뀌는지" 시뮬레이션이 된다. 기능은 많지만 **정보가 너무 많고 가시성이 나쁘다.** 로펙도 보기 어렵다.
- 그래서 **기능은 로아랩·로펙·클로아만큼, 화면은 훨씬 보기 쉽게**가 목표다. 핵심 수치를 먼저 보이고, 세부는 펼침·툴팁으로 숨긴다.

## 2. 우선순위: 전투력 + 스펙업

- 실사용자는 클로아·로펙을 자주 쓰고, **전투력과 스펙업 분야가 가장 중요**하다고 한다.
- 최우선 신규 기능: **전투력 시뮬레이터**(로아랩 기준). 캐릭터 검색 → 현재 세팅에서 장비·보석·각인·아크 패시브·아크 그리드 등을 바꾸면 전투력이 얼마나 바뀌는지. 이어서 스펙업 효율·우선순위(어디에 골드를 쓰면 전투력이 가장 많이 오르는지).
- 계산 일치 원칙 그대로: 로아랩 값과 맞추거나 공식 근거로 증명. 확실하지 않은 값은 내보내지 않는다.

## 3. UI/UX는 21st.dev·bencho.dev에서 95%

- 화면의 UI/UX(컴포넌트 모양·마이크로 인터랙션·모션)는 **https://21st.dev/ 와 https://bencho.dev/ 에서 95%를 가져와** 쓴다.
- 앞선 "목표 사이트 외관 90% 따라가기"는 **기능·정보 구조**에만 남기고, **외관은 이 두 사이트 기준**으로 바꾼다.
- 조건: 컴포넌트마다 라이선스 확인(출처·라이선스를 코드 주석 또는 NOTICE에), 성능 우선 규칙(경로당 +30KB gz, transform/opacity, 4배 감속 기준) 그대로, 라이트·다크·접근성 유지.

## 4. 404 페이지

- 404s.design의 A Color Bright 항목(원본 https://www.acolorbright.com/en/404)을 사용한다. 특징 태그: 커스텀 커서·hover 효과·인터랙티브·장난스러움.
- 동작·구조를 가져오고 로고·문구·색은 우리 것으로(원본 그림·글자 그대로 복제 금지).

## 5. 아이콘은 Iconsax로 전부 교체

- https://app.iconsax.io/ 아이콘으로 사이트 아이콘을 전부 바꾼다.
- **무료판(Free icons) 아이콘만 쓴다**(사용자 지시). Pro·유료 아이콘은 대체 후보로도 쓰지 않는다. 무료판에 맞는 모양이 없으면 글자로 두거나 가장 가까운 무료 아이콘을 쓰고 PR에 이유를 적는다.
- 라이선스: Iconsax 무료 라이선스는 개인·상업 사용 가능, 저작권 고지 유지, 아이콘 파일 단독 재배포 금지(코드의 일부로만). 출처: https://docs.iconsax.io/license-and-terms/license — 디자인 시스템이 전문을 읽고 확인.
- npm `iconsax-react`는 MIT 래퍼지만 공식 팀이 아닐 수 있다. 공식 배포 경로(SVG·패키지)를 확인하고, 쓰는 아이콘만 번들(트리 셰이킹).
- 게임 아이템·등급 아이콘(공식 API 이미지)은 그대로 둔다. 바꾸는 것은 UI 아이콘(메뉴·버튼·상태 등)이다.

## 6. 돌파고 삭제

- 돌파고 화면·메뉴·라우트·sitemap·테스트를 지운다. 옛 주소는 도구 목록으로 영구 이동(308).
- 11:19의 돌파고 피아식별 작업은 **취소**. 피아식별 공통 규칙(추천=배지, 손해=빨강+아이콘, 색만으로 구분 금지)과 3초 테스트는 다른 도구 화면에 계속 적용.

## 7. "밋밋하다" 수정안

- 11:55 수정안 4가지(홈 대표 배너, 판 깊이, 반복 줄 묶기, 섹션 머리 아이콘)는 위 3·5절(21st.dev·bencho.dev, Iconsax) 기준으로 디자인 시스템이 다시 짠다.

## 8. 공개 기준 (사용자 결정 2026-10-10 19시대)

전체 흡수율 50% 대신 **핵심 기능 기준**으로 공개를 정한다. 아래를 모두 넘으면 도메인을 연결한다(조용한 공개 → 기준 확인 → 홍보).

| 기준 | 목표 |
|---|---|
| 전투력·스펙업(최우선) | 캐릭터 화면의 전투력 정보가 클로아·로펙·로아랩 수준, 전투력 시뮬레이터 최소 1차판(로아랩과 대조 통과) |
| 캐릭터 검색 화면 | 직접 경쟁 4곳(일로아·로아와·클로아·로펙) 캐릭터 화면 기능 흡수율 80% 이상 |
| 계산 정확도 | 원인 모를 불일치(P0) 0건 |
| 나머지(시세·도구·통계 등) | 공개 뒤 계속 추가 |

- 흡수율 계산: (있음 + 부분×0.5) ÷ 그 범위 기능 수. 레퍼런스가 전체·핵심 두 숫자를 같이 보고한다.

> **2026-10-11 변경(사용자):** 캐릭터 화면 공개 기준을 "직접 경쟁 4곳 80%"에서 **"일로아 캐릭터 화면 100% 흡수"**(모든 탭·모든 상세 툴팁·아바타 캐릭터 이미지 포함)로 올린다. 근거: [[사용자 지적 2026-10-11 오후]] 5.

> **2026-10-11 16:19 공개 기준 변경(사용자):** "최소한 로펙·클로아 전부 흡수하고 서버 열자." 근거: 로아 유저 피드백 — 지금 기준으로는 사람들이 쓸 이유가 없다. → **도메인 공개(사이트 열기) 조건 = 로펙·클로아 기능 100% 흡수**(정보는 같게·디자인은 우리 것, 계산 값은 대조 통과) + 일로아 캐릭터 화면 100% + P0 0건. 이전 §8 기준(시뮬레이터 1차판·캐릭터 80%)은 이 기준에 포함되어 대체된다. 흡수율은 레퍼런스 [[흡수 현황]]에서 로펙·클로아 열을 기준으로 집계.

> **2026-10-11 16:39 범위 확인(사용자):** 로펙·클로아 흡수는 **캐릭터 정보만이 아니라 사이트 전체**(모든 메뉴·도구·랭킹·통계·시세·일정·원정대·커뮤니티성 기능 등). 공개 기준 = 로펙·클로아 **사이트 전체 기능** 100%. 다른 목표 사이트(일로아·로아와·로아랩 등)도 전체 기능을 흡수 대상으로 계속 진행(공개 뒤에도).
