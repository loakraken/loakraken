# 원정대 카드 기록 (F-6, card-record-v1)

공식 API에는 카드 도감이 없다. 일로아("원정대 카드 기록"), 로아와("카드 보관함"), 클로아("획득한 카드 세트")는 모두 원정대 캐릭터가 검색될 때 장착한 카드를 기록해 최고치를 보여 준다. 우리도 같은 방식이다. 사용자 검색과 통계 수집기(B-3)가 armory를 받을 때마다 기록하므로, 검색만 쓰는 사이트보다 빨리 채워진다.

카드와 각성은 원정대가 공유한다. 그래서 원정대 캐릭터 누구의 기록이든 원정대 보유로 본다. 값은 실제 보유의 **하한**이다. 장착한 적 없는 카드는 모르고, 각성을 올렸으면 다시 관측될 때 갱신된다.

## 기록

| 시점 | 저장 |
|---|---|
| 캐릭터 검색 armory 수집(캐시 미스), 수집기 프로필 갱신 | `character_card`: 캐릭터별 카드 최고 각성. 각성이 같거나 높을 때만 바꾼다 |
| 같은 응답 | `card_set_member`: 세트 효과의 `CardSlots`로 세트 구성원을 학습한다 |
| 같은 응답 | `card_set_effect`: 효과 이름 `세트명 N세트 (M각성합계)`에서 장수·각성합계·문구를 학습한다 |
| 같은 응답 | `characters.position`: 포지션(position-v1)을 판정했으면 저장한다 |

- 기록 실패는 검색·수집을 막지 않는다. 지표 `loakraken.character.cards.writes{outcome}`
- 관측 이력 기능(`character.history.enabled`)을 따른다. 꺼져 있으면 기록하지 않고, 조회는 503 `CARD_COLLECTION_DISABLED`다.

## 조회 `GET /api/v1/characters/card-collection?characterName=`

1. `/siblings`와 같은 캐시로 원정대를 받는다. 공식 호출은 최대 1회다.
2. 같은 서버 캐릭터만 원정대로 본다.
3. 원정대 캐릭터들의 카드 기록을 카드별 최고 각성으로 합친다. `recordedBy`는 그 기록을 남긴 캐릭터다.
4. 학습한 구성원으로 세트를 구성한다.
   - 각성 높은 카드부터 최대 6장을 쓴다.
   - 2장 이상일 때만 세트로 본다.
   - 효과는 장수와 각성합계 조건을 모두 채우면 `active`다.
   - `activeAwakening`은 달성한 가장 높은 각성합계 단계다.
5. 속성 6칸은 일로아 매핑을 따른다. 순서는 성·암·뇌·토·수·화다.

| element | 딜러 | 서포터 |
|---|---|---|
| LIGHT | 세상을 구하는 빛 | 남겨진 바람의 절벽 |
| DARK | 카제로스의 군단장 | 창의 달인 |
| LIGHTNING | 날랜 뇌전의 숨결 | 몰아치는 뇌전의 가호 |
| EARTH | 굳센 대지의 숨결 | 잠재우는 대지의 가호 |
| WATER | 거센 파도의 숨결 | 노래하는 파도의 가호 |
| FIRE | 힘찬 화염의 숨결 | 피어나는 화염의 가호 |

- 기록이 없어도 200이다. 칸의 `record`는 null이고 `cards`·`sets`는 빈 배열이다.
- 아무도 장착한 적 없는 세트는 구성원을 몰라 `sets`에 나오지 않는다. 같은 세트를 누구든 한 번 장착하면 그때부터 모든 원정대에 반영된다.

| 오류 | 상황 |
|---|---|
| 400 INVALID_REQUEST | 이름 누락·형식 오류 |
| 404 CHARACTER_NOT_FOUND | 공식 원정대에 없음 |
| 429·502·504 | 원정대 공식 호출 실패 |
| 503 CARD_COLLECTION_DISABLED·CARD_COLLECTION_UNAVAILABLE | 기능 꺼짐·DB 오류 |
| 503 LOST_ARK_NOT_CONFIGURED·CHARACTER_CACHE_UNAVAILABLE | 키 없음·캐시 오류 |

## 기록 채우기 `POST /api/v1/characters/card-collection/refresh?characterName=`

우리 기록은 지금부터 쌓인다. 그래서 처음에는 일로아·로아와보다 빈칸이 많다. 원정대의 기록되지 않은 캐릭터를 한 번에 조회해 채운다(PM #96 P2-2, 프론트 A안).

- 대상: 같은 서버 원정대 중 최근 7일 안에 프로필 관측에 성공하지 못한 캐릭터
  - 아이템 레벨이 높은 순으로 1회 최대 12명
- 조회는 캐릭터 검색(armory)과 같은 경로다. 사용자 몫 게이트·캐시·카드 기록이 그대로 적용된다.
- 공식 호출은 1회 최대 12회다. 원정대는 최대 24명이므로 분당 90회 예산의 13% 이내다. 원정대 목록은 `/siblings` 캐시를 쓴다.
- 호출 한도·시간 초과·공식 오류를 만나면 멈춘다. 나머지는 `remaining`으로 돌려준다.
- 같은 원정대(서버 + 원정대 이름 집합의 해시)는 10분에 1회만 받는다(Valkey `cards:v1:refresh:*`, SET NX).
  - 쿨다운 중이면 429 `CARD_COLLECTION_REFRESH_COOLDOWN`과 `Retry-After`(초)를 준다.
  - Valkey 장애 시에는 받지 않는다(503 CHARACTER_CACHE_UNAVAILABLE).
- 응답: rosterCharacters, refreshed, skipped(최근 기록 있음), failed, remaining, nextAvailableAt
- 카드 기록은 비동기로 저장한다. 응답 뒤 card-collection을 다시 조회하면 된다.

## 검증 (2026-10-08)

- 언새늘(아만): 원정대 6명 검색(공식 호출 6회 + 원정대 1회), 5명 기록, 성 6장 30각. 일로아의 "원정대 카드 기록"(성 30각, 나머지 미기록)과 같다.
- 성갬(루페온 바드, SUPPORT): "신념의 길" 6장 30각. 서포터 6칸에는 속하지 않아 모두 null이다. 일로아 화면도 같다.
- 클로아(뇌·화 24각)와 로아와(카드 27장)에만 있는 값은 그 사이트들이 예전에 관측한 기록이다. 우리 기록은 이제부터 쌓인다.

## 후속
