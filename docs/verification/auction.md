# 경매 입찰가 교차 검증 (2026-10-09)

레이드 전리품 경매 입찰가 계산(성장 도구 `loakraken-web` `lib/tools/auction.ts`, 일로아 방식)을 두 목표 사이트로 대조한다.

**결론: 일치.**
- 판매 손익 분기와 수수료는 일로아·로아랩이 같다.
- 선점 입찰가는 반올림 방식 차이로 1G 다를 수 있다.
- 공식 근거가 없는 두 규칙(수수료 5%의 비율 문구, 10% 재입찰)은 화면에 "추정"을 유지한다.

## 대조

- 일로아 값은 성장 도구팀 관찰(볼트 `90 성장 도구/경매 입찰가 설계.md`)이다. 로아랩 값은 계산 검증팀이 같은 조건으로 다시 입력해 읽었다.
- "직접 사용"은 사이트마다 정의가 다르다.
  - 일로아는 수수료를 빼지 않는다.
  - 로아랩은 수수료를 빼서 판매 손익 분기와 같다.
  - 크라켄은 일로아 정의를 따른다(PM 결정 2026-10-08).

## 공식 근거 확인

- 게임 가이드 「거래소」는 판매 수수료가 있고 판매 완료 시 수수료를 뺀 금액을 받는다고 설명한다. 비율(5%)은 글로 확인하지 못했다(이미지·게임 안 표시로 추정).
- 경매에서 다음 입찰이 10% 이상 높아야 한다는 규칙은 공식 문구를 찾지 못했다. 두 사이트가 같은 기준(÷1.1)을 쓴다.
- 판정: 두 규칙 모두 TARGET_SITE 기준이다. 성장 도구 화면의 "추정" 표기를 유지한다.
