# 비교 대상 사이트 검증과 백엔드 반영

검증일: 2026-10-04 KST. 최초 목록은 개발 기준서 **1.1 참고 서비스**, 원문 17–26행에 있다.
아래의 기능 확인은 공개 페이지·공식 안내·운영자 공개 자료에 한정한다. 계산 정확도나 서비스 전체의 우열을 검증한 결과가 아니다.

## 확인 방법과 한계

- 공개 페이지 본문에서 읽은 내용, 검색 수집본, 공식 문서/소스를 구분했다.
- 브라우저 자동화가 로컬 샌드박스 초기화 오류로 실행되지 않았다. 클릭 후 결과, 모바일 레이아웃, 반응 속도는 미검증이다.
- 블박사의 LOPEC·LOAWA·ILOA·KLOA 상세 URL 조회는 웹 도구에서 접근 오류였다. 해당 캐릭터가 없거나 사이트가 장애 상태라는 뜻은 아니다. 사이트 간 동일 캐릭터 수치 비교는 완료하지 못했다.
- ZLOA 검색 수집본의 404와 LoaTodo 검색 수집본의 점검 문구도 현재 서비스 장애로 단정하지 않는다.
- 이번 작업에서 사용자 Lost Ark API 키를 타 사이트에 입력하지 않았고, 공식 API 실조회도 추가하지 않았다.

## 구현 결정

1. 이번 백엔드 증분은 **관측 근거 기반 진단**이다. 기존 analysis의 수치와 null에 근거하여 설명한다. 임의 점수·DPS·강화 비용은 넣지 않는다.
2. 진단은 정보 부족과 관측된 비활성 세팅을 구분한다. 알려지지 않은 값을 0 또는 false로 취급하지 않는다. 목록이 비었다는 사실만으로 미착용을 확정하지 않는다.
3. 진단 코드, 규칙 버전, 응답 내 근거 경로를 공개한다. 프론트는 설명 문구를 파싱하지 않고 코드로 분기한다. 프론트 구현은 다른 채팅 담당이다.
4. 관측 변화 비교는 저장·재제공 범위를 확인한 뒤 진행한다. 관측 저장과 이력 조회는 기본 비활성화했다. 수집 간격·규칙 변경·캐릭터 동일성의 한계를 명시해야 한다.
5. 비용/추천/시뮬레이션 전에 공식 패치와 데이터, 직업/세팅별 계산 가정, 재현 가능한 검증 표본을 확보한다. 경쟁 서비스 수치와 우연히 일치하는 것만으로 공식을 검증했다고 판단하지 않는다.

이 결정은 공개 자료에서 도출한 LOAKraken의 구현 판단이다. 다른 서비스에 해당 원칙이나 기능이 없다는 주장은 아니다.

## 재검증할 항목

### 2026-10-04 추가 교차 검증

- LOPEC [공식 공지](https://lopec.kr/)의 2026-03-16 원정대 주간 골드·간단 체크리스트·로그 기능도 비교 범위에 포함한다. 성장 경로·비용·시뮬레이션 안내까지 있으므로 스펙 점수만 제공하는 서비스로 분류하지 않는다.
- ILOA는 홈 외에 [통계](https://iloa.gg/statistics), [랭킹](https://iloa.gg/ranks), [도구](https://iloa.gg/tools)도 확인했다. 통계는 등록된 캐릭터 기준이며 집계 수·시각을 표시한다. 홈 카운터와 통계 모집단 수, 게임 전체 유저 수를 혼동하지 않는다.
- RLoA [개발 사이트](https://dev.rloa.gg/) 검색 수집본의 기능 메뉴·접속 인원 문구는 추가 조사 단서다. 직접 본문 추출과 기능 동작은 미검증이므로 운영 상태나 현재 이용자 수를 확정하는 근거로 쓰지 않는다.
- 공식 저장 약관·거래 API 경로·버전 의미를 포함한 결론은 [교차 검증 기록](source-verification.md)을 참고한다.

### 남은 확인

- 브라우저 사용 가능 시 블박사 검색부터 갱신 시각, 원정대, 성장 추천 입력까지 같은 조건으로 관찰한다.
- 각 서비스가 표시한 게임 데이터와 자체 계산 수치를 분리해 비교한다. 타 서비스의 점수와 공식 전투력은 같은 척도로 보지 않는다.
- 로그인·API 키 등록 없이 확인 가능한 범위부터 진행하고, 확인하지 못한 항목은 미검증으로 유지한다.
