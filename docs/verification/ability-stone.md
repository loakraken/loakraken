# 돌파고(어빌리티 스톤 세공) 확률 규칙 교차 검증 (2026-10-09)

돌파고는 어빌리티 스톤 세공의 최적 줄 추천이다(성장 도구, 로아또·목표 사이트 C 기능). 이 문서는 확률 규칙을 공식 표와 목표 사이트로 검증한 결과다.

**결론: 일치.** 공식 결과표 4개와 목표 사이트 C 값 2개가 규칙으로 재현된다.

## 규칙

| 항목 | 값 | 출처 |
|---|---|---|
| 성공 확률 | 75%에서 시작, 성공 −10%p, 실패 +10%p, 범위 25~75%, 세 줄이 확률을 공유한다 | OFFICIAL_DISPLAY(역산): [확률 정보 공개 「어빌리티 스톤 자동 세공」](https://lostark.game.onstove.com/Probability/어빌리티%20스톤%20자동%20세공)(2025-12-10). 수치가 문장으로 공개되지 않아 표로 확인했다 |
| 세공 칸 | 10·9·8·6(5 이하 존재) | 공식 결과표 4개, 게임 가이드. 등급↔칸 매핑은 추정 |
| 레벨 | 증가 각인: 성공 6/7/9/10회 → 1~4레벨. 감소 각인: 균열 5/7/10회 → 1~3레벨 | 게임 가이드 「아이템 > 각인」(2026-06-24) |

## 방법과 결과

1. **공식 표 대조**
   - 확률을 세 줄이 공유하면, 세 줄 성공 횟수의 **합**의 분포는 어느 줄을 깎는지와 상관없다.
   - 그래서 규칙만으로 3N회 연쇄의 총합 분포를 계산해 공식 결과표의 합 분포와 비교했다.

   | 칸 | 최대 차(%p) |
   |---|---|
   | 10 | 0.00093 |
   | 9 | 0.00046 |
   | 8 | 0.00036 |
   | 6 | 0.00011 |

   - 공식 표 값의 반올림 수준이다.
   - 다른 규칙은 크게 어긋났다: ±5%p는 최대 20%p, 65% 시작은 9%p다.
2. **목표 사이트 C 대조**: 수동 최적 선택(목표 달성 확률 최대) 동적 계획법으로 계산했다.

   | 목표(10칸, 감소 4 이하) | 계산 | 목표 사이트 C | 필요 돌 25/50/90% |
   |---|---|---|---|
   | 7·7 | 4.8145% | 4.8% | 6/15/47 (목표 사이트 C 같음) |
   | 9·7, 7·9, 10·6, 6·10 | 0.1356% | 0.14% | 212/511/1,697 (목표 사이트 C 같음) |

## 범위 밖

- 공식 자동 세공의 세 줄 결합분포. 자동 세공은 "목표 레벨 달성 확률을 최대로 하는" 정책인데, 동률 처리 등 세부 기준이 공개되지 않았다. 최적 정책으로 계산해도 최대 1~2%p 차이가 남는다. 돌파고는 사용자가 줄을 고르므로 영향이 없다.
- 등급별 칸 수 매핑(공식 표 없음)
