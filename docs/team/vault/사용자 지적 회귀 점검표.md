# 사용자 지적 회귀 점검표

관련: [[사용자 지적 2026-10-11 오후]], [[PM 검토 기록]], [[출장 주간 계획 2026-10-12~16]]

사용자(10-12): "백엔드도 그렇지만 프론트 쪽 특히 검수를 확실하게 해. 지금까지 내가 지적했던 것들 두 번 다시 없게."

## 쓰는 법

- **모든 PR**: 작성 팀은 PR 본문에 '회귀 점검표 확인' 칸을 둔다. 해당 줄 번호와 결과(통과/해당 없음)를 적는다.
- **검토 PM**: PM-프론트·PM-백엔드는 해당 줄을 직접 확인한다. 화면 PR이면 3테마(라이트·딤·다크)와 넓은 화면·360px에서 브라우저로 직접 확인하고, 캡처를 PR에 남긴다.
  - 하나라도 어기면 **P1**이다. 병합하지 않는다.
- **자동 검사**: 아래 '자동' 열이 있는 줄은 CI에서 막는다. 사람이 놓쳐도 CI가 실패하게 만드는 것이 목표다.
- **새 지적**: 사용자가 새로 지적하면 PM 총괄이 같은 날 이 표에 줄을 추가한다.
- **매일 점검**: PM-프론트가 하루 한 번 주요 화면 전체를 3테마로 훑어본다. 결과를 PM 총괄 전달함에 한 줄로 남긴다.

## A. 화면 공통 (프론트·디자인 시스템)

| A26 | 색 의미(수집품 완료·미완료, 10-12) | 상태 색은 사용자가 정한 대로 쓴다. 완료=파랑, 미완료=기본 글자색 | 검토 |

| A32 | 360px에서 한글 단어가 중간에서 줄바꿈됨, 시세 등락 숫자 "▲8.8 (4.7%)"가 두 줄(PM-프론트 전수 점검, 10-12) | 본문은 전역 word-break: keep-all(한글 단어 단위 줄바꿈). 숫자·등락·단위 묶음은 한 덩어리(nowrap). 링크 텍스트 단어 쪼개짐 금지 | e2e: 360px 대표 화면 줄바꿈 검사 |
