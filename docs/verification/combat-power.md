# 전투력 모델 검증 (2026-10-08)

공식 전투정보실 전투력(`ArmoryProfile.CombatPower`)을 장비·세팅으로 설명하는 모델의 잔차를 잰다. 예상 전투력·딜 증가량·로펙형 점수·스펙업 가이드는 이 모델을 쓴다.

**결론: 미검증.** 딜러 로그 잔차 표준편차가 4.27%다. 공개 기준(2% 이하)을 넘으므로 공개 응답에 모델 전투력이나 변화량을 넣지 않는다.

### 제외 표본 2명 (`excluded`)

- 같은 날 로아와 랭킹은 4,499.66을 보여 줬지만 공식값은 1,427.71과 1,370.21이었다(−68%, −70%).
- 장비·코어·아크 패시브는 1750급 완성 상태다. 공식 CombatPower가 현재 장비와 맞지 않는 것으로 보고 뺐다.
- 포함하면 최선 가설(E1)의 SD가 10.79%로 커진다. `--include-excluded`로 재현할 수 있다.
- 백엔드가 이 모델을 쓸 때도 공식값과 모델값이 크게 어긋나면(예: −40% 이하) 불일치 표본으로 다뤄야 한다.

## 모델

`ln(전투력) = c + ln(공격력) + Σ ln(1 + 고정 요소) + Σ β·자유 특성`, 최소제곱.

| 요소 | 처리 | 출처 |
|---|---|---|
| 공격력 | H0~H2: 공격력 Tooltip의 기본 공격력 + 연마·그리드 공격력%. H3부터: 공식 공격력 총합 | 공식 |
| 무기 품질 추가 피해 | 그대로 | 공식 문구, 환산은 추정 |
| 치명·특화·신속 | 합 × 0.03% | 추정 |
| 아크 패시브 포인트 | 진화(40 초과분) 0.5%/pt, 깨달음 0.7%/pt, 도약 0.2%/pt | 추정 |
| 각인 | 유물 4레벨 계수 범위[스톤0, 스톤4], 스톤 증가는 0/3/3.75/5.25/6(원한 설명 수치 비율) | 범위는 추정, 스톤 비율은 공식 설명 |

| 보석 | 4티어(겁화·작열·광휘) 1.28% + 레벨당 0.64%, 3티어 0.48~6.4% | 추정 |
| 연마·아크 그리드 효과 | 추가 피해 ×0.769, 적주피·공격력% ×1, 치적 ×0.774, 치피 ×0.3 | 문구는 공식, 환산은 추정 |

## B-7 결론: 광휘 보석·각인 유물 0~3레벨

부트스트랩 400회, 95% 신뢰구간이다.

| 질문 | 추정 | 판정 |
|---|---|---|
| 각인 유물 레벨 배율(E2, 1이면 E1 규칙과 같음) | 1.003 (0.593~1.419) | 유물 0~3레벨은 E1 선형 규칙과 맞는다. 유물<4·1740 이상 31명의 RMS가 7.23% → 5.42%로 줄었다 |
| 광휘 추가 배율(G1, 0이면 겁화·작열과 같음) | +0.010 (−0.024~+0.041) | 광휘는 겁화·작열과 같은 계수다. 이전 노트의 광휘 7~8레벨 −25~27% 이탈은 코어·팔찌 요소 누락 때문으로 보인다 |
| 광휘 피해형/쿨감형(G2) | +0.012 / +0.008 (각 ±0.06) | 둘을 구분할 근거가 없다 |

이 두 규칙은 잔차를 줄이거나 바꾸지 않는다. 확인된 것은 계수의 형태다. 모델 전체는 여전히 미검증이다.

## 아직 안 맞는 것

- 1740 이상 딜러의 RMS는 3.83%다. 목표 2%에 못 미친다.
- 최대 이탈 표본
  - 하이브리드 직업 딜러: 홀리나이트 −16%·−13%, 도화가 +17%. 직업 각인이 계수표에 없다.
  - 1740 미만이면서 보석·코어 미장착: −12~+9%
- 질서 코어 10P·14P 계수가 서로 상쇄된다(+0.111, −0.065). 14P 미만 코어 표본이 적어 불안정하다.
- 원인 후보
  - 직업 각인과 하이브리드 직업 계수
  - 팔찌 특수 옵션(방향성·악마 계열 피해·무기 공격력 버프) 환산
  - 연마·아크 그리드 효과의 환산 계수(현재 2025-07 추정치)
  - 질서 코어 구간별 실제 계수
  - 아크 패시브 노드(현재 포인트만 반영)
