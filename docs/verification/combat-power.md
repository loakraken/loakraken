# 전투력 모델 검증 (2026-10-08, 후속 2026-10-09)

공식 전투정보실 전투력(`ArmoryProfile.CombatPower`)을 장비·세팅으로 설명하는 모델의 잔차를 잰다. 예상 전투력·딜 증가량·로펙형 점수·스펙업 가이드는 이 모델을 쓴다.

**결론: 미검증.** 최선 가설(C1)의 표본 밖 잔차(5겹 교차검증)는 딜러 전체 4.67%, 1740 이상 3.89%다. 공개 기준(표본 밖 2% 이하)을 넘으므로 공개 응답에 모델 전투력이나 변화량을 넣지 않는다. 후속 결과는 아래 "2026-10-09 후속(v2)" 절에 있다.

## 모델

`ln(전투력) = c + ln(공격력) + Σ ln(1 + 고정 요소) + Σ β·자유 특성`, 최소제곱.

|---|---|---|
| 공격력 | H0~H2: 공격력 Tooltip의 기본 공격력 + 연마·그리드 공격력%. H3부터: 공식 공격력 총합 | 공식 |
| 무기 품질 추가 피해 | 그대로 | 공식 문구, 환산은 추정 |

| 각인 | 유물 4레벨 계수 범위[스톤0, 스톤4], 스톤 증가는 0/3/3.75/5.25/6(원한 설명 수치 비율) | 범위는 추정, 스톤 비율은 공식 설명 |

## 2026-10-11 재련 모델 확정 (로아랩 대조 통과)

`verification/combat-power/loalab-refine-model-2026-10-11.json`. 10-10에 막혔던 "로아랩 S·W가 아이템 합보다 크다"의 원인을 찾았다. 로아랩은 S를 아이템 합으로 만들지 않는다. **공식 기본 공격력 B에서 역산한다.**

- **모델**
  - B(공식 기본 공격력) = (R + F) × (1 + q), R = √(S × W / 6)
  - F: 팔 보호구 Tooltip "기본 공격력 +N"(+13 = 2,030, +25 = 9,050)
  - q: 기본 공격력% 합 = 보석 + 스톤 레벨 보너스 + 팔 보호구 "기본 공격력 +x%"(보석 모델의 기본 공격력%와 같다)
  - W = (무기 + 팔 보호구 무기 공격력 + 장신구 "무기 공격력 +N") × (1 + 장신구 "무기 공격력 x%" + 깨달음 카르마 레벨 × 0.1%)
  - S = 6R² / W
  - 힘민지 배수 mS = 1 + 펫 1% + 아바타(전설 2%, 영웅 1%)
- **단계**
  - 방어구: S' = S + Δ힘민지 × mS
  - 무기: W' = W + Δ무기 공격력 × (1 + 무기 공격력%)
  - 전투력 비 = (R × √(S'/S 또는 W'/W) + F) / (R + F)
- **확인 방법**: 로아랩 시뮬레이터가 화면에서 보내는 계산 요청과 같은 요청을, 입력을 하나씩 바꿔 보냈다.
  - B만 바꾸면 방어구 비율이 크게 변한다 → S가 B에서 나온다.
  - 아바타·카르마·장신구 무공%·스톤·보석을 바꾸면 위 식대로 변한다.
