# 재료 이름별 1개당 시세

`POST /api/v1/markets/material-prices`는 재료 이름 목록을 받아 거래소 현재 판매 목록 기준 **1개당 골드**를 돌려준다. 재련 기대 비용(`POST /api/v1/refining/plans`, [refining-plan.md](refining-plan.md))의 재료 이름을 그대로 넣어 시세로 환산하는 용도다. 구매 수량·묶음 올림 계산은 [material-quotes.md](material-quotes.md)의 견적 API가 담당한다.

## 요청

```json
{"priceBasis":"CURRENT_MIN_PRICE","names":["운명의 수호석","운명의 파편","재봉술 : 업화 [19-20]"]}
```

- `priceBasis`: `CURRENT_MIN_PRICE`, `RECENT_PRICE`, `YDAY_AVG_PRICE` 중 하나(필수). 선택한 가격이 없으면 다른 가격으로 대체하지 않는다.
- `names`: 1–20개, 각 64자 이하, 공백만 있는 이름은 거절한다. 앞뒤 공백은 지우고, 같은 이름은 처음 나온 순서대로 한 번만 응답한다.

## 계산

1. 이름마다 강화 재료 분류(`categoryCode=50000`)의 현재 판매 목록 첫 페이지를 그 이름으로 검색한다. 정렬은 최근 거래가 오름차순이다.
2. 상품 이름이 요청 이름과 **정확히 같은** 상품만 쓴다. 예를 들어 `운명의 수호석` 검색에 함께 나오는 `운명의 수호석 결정`은 쓰지 않는다.
3. 1개당 골드 = 선택 가격 ÷ 묶음 수, 소수 여섯째 자리 반올림. 같은 이름이 여러 개면 가장 싼 1개당 가격을 고른다.
4. `운명의 파편`은 거래소에 낱개가 없어 `운명의 파편 주머니(소·중·대)`를 검색한다. 공식 거래소 Tooltip의 내용물(소 1,000, 중 2,000, 대 3,000개, 2026-10-05 확인)로 나눠 가장 싼 주머니의 파편 1개당 가격을 쓴다. 이때만 `contentsPerItem`이 채워진다.

## 응답

| 필드 | 의미 |
|---|---|
| `priceBasis` | 요청한 가격 기준 |
| `items[].name` | 정규화된 요청 이름 |
| `items[].status` | `PRICED` 계산됨 / `NOT_FOUND` 첫 페이지에 같은 이름 없음 / `PRICE_UNAVAILABLE` 같은 이름은 있으나 선택 가격이 null 또는 0 |
| `items[].unitPriceGold` | 1개당 골드. PRICED가 아니면 null |
| `items[].sourceItemName`, `bundleCount`, `bundlePrice` | 근거 상품과 그 묶음 가격. NOT_FOUND면 null |
| `items[].contentsPerItem` | 파편 주머니 내용물 수. 파편이 아니면 null |
| `items[].observedAt` | 서버가 그 검색 페이지를 읽은 시각. 캐시 적중 시 원래 시각 유지 |

`NOT_FOUND`는 첫 페이지 기준이며 게임에 그 재료가 없다는 단정이 아니다. 귀속 재료(예: 일부 이벤트 재료)는 거래소에 없으므로 프론트에서 0골드 또는 제외로 처리한다.

## 호출과 오류

- 이름 하나당 검색 페이지 하나를 순차 조회한다(파편은 주머니 검색 1회). 기존 거래소 30초 캐시와 캐릭터·옵션이 함께 쓰는 90회/분·동시 4개 예산을 공유한다. 최대 20회.
- 입력 오류는 조회 전에 `400 INVALID_REQUEST`, JSON 이외 본문은 `415`, 외부 오류는 기존 429/502/503/504를 그대로 반환한다.

## 검증

- 서비스 단위 테스트: 정확 일치, 묶음 나눗셈, 파편 주머니 최저가 선택, NOT_FOUND, PRICE_UNAVAILABLE, 중복 이름 1회 조회.
- HTTP 통합 테스트: 이름 정규화와 중복 제거, 20개 초과·빈 이름·잘못된 기준 400, 415, Swagger 필수·nullable 계약. 합성 산출물은 `material-prices.json`이다.
- 2026-10-05 실제 조회(`CURRENT_MIN_PRICE`): 수호석 0.3, 돌파석 3, 아비도스 융화 재료 191, 파편 0.076667(대 주머니 230), 빙하의 숨결 435, 용암의 숨결 475, `재봉술 : 업화 [19-20]` 690, `장인의 재봉술 : 1단계` 125골드. 없는 이름은 NOT_FOUND.
