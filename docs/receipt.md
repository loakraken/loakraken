# 원정대 영수증 (receipt-v1, #173)

계산 검증 1차 규칙(볼트 `70 계산 검증/원정대 영수증 환산 규칙 (초안).md` 6절, PM 총괄 2026-10-09 승인)을 구현한다. 설계: 볼트 `10 백엔드/04 설계/원정대 영수증 API 설계.md`.

## 공개 상태

**기본으로 꺼져 있다**(`receipt.enabled=false`, `RECEIPT_ENABLED`). 사용자 지시 "계산 일치 원칙"(2026-10-09 21:56·21:59)에 따라, 로아와와의 재련 비용 차이(성공률 약 +1%p로 추정)의 원인을 계산 검증이 밝히고(공식 확률 표기 근거 또는 크라켄 수정) 완갑을 포함할 때까지 공개하지 않는다(PM 총괄 22:00 결정). 검증 서버에서만 켠다. "다른 사이트와 다를 수 있음" 문구는 쓰지 않는다.

## API

`GET /api/v1/characters/receipt?characterName=`

- 같은 서버 원정대 단위다. 원정대 목록은 원정대 캐시(공식 최대 1회)를 쓴다.
- 캐릭터별 전투정보는 캐시(5분)를 먼저 쓰고, 없을 때만 공식 armory를 부른다. 한 요청에 최대 8명만 새로 받고 나머지는 `PENDING`이다. 다시 요청하면 이어서 채운다.
- 한도·장애를 만나면 나머지를 다음 요청으로 넘긴다. 없는 캐릭터는 건너뛴다.
- 공식 원문은 저장하지 않는다. 새로 받은 캐릭터는 검색과 같이 관측 이력·카드·장비 요약에 기록된다.

## 금액에 넣는 것

| 분류 | 규칙 |
|---|---|
| 장비 재련 | 무기·방어구 5부위. 이름으로 등급(업화·전율, 4티어)을 정한다. +10에서 현재 단계까지 단계마다 `t4-refining-v1` 한 단계 기대 비용을 더한다. 단계마다 숨결 사용·미사용(업화 11~20단계는 책 사용·미사용까지) 조합 중 가장 싼 쪽. 업화 18단계 이하 성장 지원. 재료는 현재 최저가 1개당(`material-prices`와 같은 환산, 운명의 파편은 주머니 환산) |
| 보석 | 이름에 "(귀속)"이 없으면 거래 가능. 경매장 시세 표(겁화·작열 1~10레벨) 최저 즉시 구매가. 광휘 등 표에 없는 종류는 `NO_PRICE`, 칸이 비면 `PENDING`(금액 제외) |

## 산정 제외 사유(`excluded[].reason`)

| 코드 | 뜻 |
|---|---|
| UNSUPPORTED_GRADE | 업화·전율 4티어가 아닌 장비(3티어, 결단 등 이벤트 무기, 에스더 무기 등) |
| UNSUPPORTED_STAGE | 재련 규칙 범위(11~25) 밖 |
| ARM_GUARD | 완갑(1차 제외) |
| ADVANCED_REFINING | 상급 재련(재련 v2 전까지). 4티어 장비가 있으면 캐릭터마다 한 줄 |
| PRICE_UNAVAILABLE | 재련 재료 시세를 찾지 못함 |

현재 단계가 10 이하인 부위는 비용 0으로 `parts`에 둔다(제외 아님). 규칙 6절의 "0~10단계 산정 제외"와 같은 뜻이다: +10까지는 세지 않고 +11부터 더한다.

상급 재련 단계는 공식 응답 해석이 없어 읽지 못한다. 그래서 `ADVANCED_REFINING`은 4티어 장비가 있는 캐릭터마다 "상급 재련이 있다면 산정하지 않습니다"로 붙는다(PM 총괄 결정: 공식 확률 공개 전까지 산정 제외 유지).

## 금액에 넣지 않는 것

젬·팔찌·악세는 개수만 `notIncluded[]{kind, reason: VERIFYING, count}`로 준다. 젬은 가공 기대 비용 모델 검증 뒤 넣는다(PM 결정 4).
