# 기본 분석

검색 응답의 `data.analysis`는 같은 수집 시각의 구조화 데이터를 요약합니다.
Spring이나 외부 호출 없이 도메인에서 순수 계산하고, 캐시 적중에서도 해당 캐시의 관측값을 기준으로 계산합니다.
추가 외부 호출이나 DB 저장을 발생시키지 않습니다.

| 필드 | 의미 |
|---|---|
| equipmentCount | 수집된 장비 항목 수 |
| equipment | [장비 Tooltip 해석](character-search.md) 결과의 해석/해석 불가 장비 수, 재련 단계 최소·최대·분포, 품질 최소·최대·평균, 장비가 제공하는 아크패시브 포인트 이름별 합계 |
| gems | 보석 수, 미확인 레벨 수, 최소·최대·평균, 오름차순 레벨 분포 |
| cards | 카드 수, 미확인 각성 수, 확인 가능한 각성 합계 |
| engravings | 각인 슬롯 수와 기존·아크패시브 효과 수 |
| arkPassive | 활성 여부와 포인트별 관측 값 |
| arkGrid | 코어 수와 활성·비활성·미확인 보석 수 |

제공되지 않은 섹션은 `null`입니다. 제공된 빈 목록은 건수 0으로 표현합니다.
내부 목록이 미제공이어도 정규화된 집계 건수는 0일 수 있으므로, 원천 부재와 실제 빈 목록은 [coverage](character-observation.md)로 구별합니다. 해당 미제공 목록의 진단 observedCount는 null입니다.
보석 레벨은 양수인 값만 평균에 포함하고 소수 둘째 자리까지 반올림합니다.
계산할 레벨이 없으면 최소·최대·평균은 `null`이며 0으로 대체하지 않습니다.
카드 각성 수는 null, 음수, 해당 카드의 최대 각성보다 큰 값을 미확인으로 구분합니다.
포인트의 null·음수는 미확인 값 null로 표시합니다. 비활성 false와 포인트 0은 유효한 값입니다.

예를 들어 보석 레벨이 9, 7, 9, 미확인이면 count는 4, unknownLevelCount는 1,
평균은 8.33, 분포는 7레벨 1개와 9레벨 2개입니다.
이 평균은 보석 종류나 직업별 가중치를 적용하지 않은 단순 집계입니다.

### 포지션 판정 — position-v1

`analysis.position`(DEALER/SUPPORT/null), `positionEvidence`, `positionRuleVersion`. 일로아의 딜러/서포터 구분(전투력 색·랭킹 필터)에 대응한다.

| 조건 | 판정 | 근거 |
|---|---|---|
| 서포터 가능 직업(바드·홀리나이트·도화가·발키리)이 아님 | DEALER | 직업명 |
| 깨달음 노드에 서포터 노드 보유 | SUPPORT | 노드명 |
| 깨달음 노드에 딜러 노드 보유 | DEALER | 노드명 |
| 둘 다 없음(아크패시브 미제공·미습득) | null | null |

- 서포터 노드: 바드 절실한 구원, 홀리나이트 축복의 오라, 도화가 만개, 발키리 해방자. 2026-10-05 일로아 서포터 랭킹 표본 4명을 공식 API로 확인했으며 바드·도화가·홀리나이트는 **깨달음 2티어**, 발키리는 1티어였다. 티어와 무관하게 노드 이름으로 판정한다.
- 딜러 노드: 바드 진실된 용맹, 홀리나이트 심판자, 도화가 회귀, 발키리 빛의 기사(빛의 기사는 일로아 딜러 랭킹 표본, 나머지는 프론트 조사 기준).
- 판정은 아크패시브 효과 설명 `깨달음 N티어 {노드} Lv.M` 형식을 사용한다. 신규 서포터 직업이 추가되면 규칙 버전을 올린다.

### 목표 사이트 공통 집계 (2026-10-05)

공식 전투정보실과 로아와·클로아·일로아에서 같은 캐릭터(언새늘)로 관찰한 공통 표시를 원천 값만으로 제공한다.

- `equipment.qualityGroups`: `WEAPON_ARMOR`(무기·투구·상의·하의·장갑·어깨)와 `ACCESSORY`(목걸이·귀걸이·반지) 순서로 항상 두 항목. 그룹별 개수·최소·최대·평균. 스톤·팔찌 등 나머지는 그룹에서 제외하며 기존 합산 품질 필드는 유지한다. 언새늘 98.33 / 85.8, 일로아 표시 98 / 86.
- `gems.damageEffectCount` / `cooldownEffectCount` / `unknownEffectCount`: 보석 스킬 효과 줄이 정확히 `피해 N% 증가`면 피해, `재사용 대기시간 N% 감소`면 쿨감, 그 외는 미확인. 공식 전투정보실 보석 탭 표기와 같은 기준이며 언새늘 4 / 7 / 0.
- `arkGrid.orderPoints` / `chaosPoints`: 코어 이름이 `질서`/`혼돈`으로 시작하는 슬롯 포인트 합. 해당 코어가 없으면 null. 최대 포인트는 근거가 없어 제공하지 않는다. 언새늘 53 / 51.

장비 집계는 `detail`이 있는 장비만 사용하며, 재련 단계·품질이 없는 장비는 해당 집계에서 제외합니다. 품질 평균은 무기·방어구·장신구를 구분하지 않은 단순 산술 평균(소수 둘째 자리 HALF_UP)이며 값이 없으면 `null`입니다. 예를 들어 품질 100, 95, 87이면 평균은 94.00입니다. 장비 포인트 합계는 장비 Tooltip에 표시된 값의 합이며 아크패시브 섹션의 전체 포인트와 다를 수 있습니다. 재련 분포와 품질은 성능 점수나 강화 추천이 아닙니다.

카드 각성 합계는 세트 효과의 단계나 성능 점수가 아닙니다. 장비 개수도 슬롯 충족 판정이 아닙니다.
Kraken Score, 예상 DPS, 스펙업 효율과 추천은 계산 모델과 실제 데이터 검증 후 별도로 제공합니다.
