# 스킬 쿨타임 검증

## 2026-10-12 보석 반영 쿨타임 (PM 총괄 판정 ④(b))

`verification/skill/official-gem-cooldown-2026-10-12.json`. 표본은 5명 51개 스킬이다(언새늘 외 익명 c01~c04). 공식 API 호출은 10회다(combat-skills·gems 각 5회).

- **정의**: 보석 반영 쿨타임 = 공식 원문 재사용 대기시간 × (1 − 보석 쿨감 %).
  - 원문: armory combat-skills Tooltip의 "재사용 대기시간 N초". 선택한 트라이포드가 반영된 값이다.
  - 보석: armory gems의 `Effects.Skills[].Description` "재사용 대기시간 x% 감소"
- **근거**: 두 값 모두 공식 원문이라 계산 결과가 확정된다.
  - 원문 쿨타임에는 보석 감소가 들어 있지 않다. 언새늘 터닝 슬래쉬는 쿨감 보석 16%가 있는데도 원문이 15초다.
- **넣지 않는 것**: 각인·아크 패시브 노드·신속·직업 아이덴티티 감소. 두 출처가 대조된 것만 단계적으로 더한다.
- **다른 사이트와의 관계**: 다른 사이트의 쿨타임·주기는 아이덴티티까지 넣은 값이다. 예를 들어 c01 라스트 그래피티는 원문 22초, 보석 반영 16.72초, 다른 사이트 주기 9.2초다. 정의가 달라 비교 대상이 아니다.
- **1타 피해**: 보류. 공식 원문에 피해 수치가 없다.
