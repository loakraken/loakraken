# 아크 그리드 젬 가공 확률 모델 검증 (2026-10-09)

젬파고(로아또)와 젬 교체 효율(목표 사이트 A)의 기반인 젬 가공 확률 모델을 검증한다. 원정대 영수증의 젬 산정도 이 모델을 쓴다.

**결론**
- **성공 확률: 공식 확률표 규칙으로 재현됨.** 로아또 7/7이 반올림 범위 안이다.
- **기대 비용: 근사(−9.8%~+0.3%), 미검증.** 화면에는 확률을 "공식 확률표 기준", 비용을 "추정"으로 표시해야 한다.

## 방법

- `docs/verification/arkgrid-gem/sim.mjs`: 규칙 구현(추출·적용)
- `dp.mjs`: 목표 포인트 합 달성 확률 최대 정책의 동적 계획법
  - 등장 4개의 분포는 상태별 K개 표본(고정 시드)으로 근사한다.
  - 다른 항목 보기와 완료를 최적으로 고른다. 초기화는 쓰지 않는다.
- `dpcost.mjs`: 같은 정책의 기대 가공비. 목표에 도달할 수 없으면 멈춘다. 성공 1회당 비용 = 기대 가공비 ÷ 성공 확률
- `cases.mjs`: 로아또 대조 사례 실행

## 한계

- 표본 근사(K=96~128)로 확률에 ±0.3%p 안팎의 오차가 있다. 서버 구현은 4개 조합 전수 계산이나 더 큰 K를 권한다.
- 비교 대상이 한 사이트(로아또)다. 목표 사이트 A는 상태별 확률을 보여 주지 않는다.
- 효과 종류(공격력·추가 피해 등)와 의지력 효율의 전투력 가치는 이 검증 범위 밖이다. 목표는 포인트 합만 다뤘다.
